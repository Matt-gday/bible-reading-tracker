# App Icons

Create two PNG icons for the PWA manifest:
- `icon-192.png` — 192×192px
- `icon-512.png` — 512×512px

Suggested design: Gold bookmark on dark grey background, matching the app's accent colour (#C9A45C) and background (#1A1A1A).

You can use any tool (Figma, Canva, Adobe Illustrator) or generate with AI image tools.
